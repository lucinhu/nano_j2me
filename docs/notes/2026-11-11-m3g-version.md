# M3G 版本发现与属性查询修复（2026-11-11）

本轮补齐三个可独立复现的 API 行为问题：

- 编译启用 M3G 时，`System.getProperty("microedition.m3g.version")` 过去返回 `null`，现由运行时属性表返回保守的 `"1.0"`；关闭模块时不添加此属性。
- `System.getProperty("")` 过去返回 `null`，现抛出 `IllegalArgumentException`。`null` 参数仍抛出 `NullPointerException`，未知非空键仍返回 `null`。
- `Graphics3D.getProperties()` 过去遗漏规范要求的 `Integer maxViewportDimension`，现补为 `4096`，等于既有 `maxViewportWidth` 与 `maxViewportHeight` 的较小值。

## 原因与范围

原始 JBenchmark HD 的信息页先查询 `microedition.m3g.version`；返回 `null` 时直接写入 M3G `No` 并跳过反射查询 Graphics3D 属性，所以已有 `maxLights = 8` 也不会显示。这里修复的是运行时的发现接口，未修改游戏 JAR、测试成绩或截图。本轮没有重新运行 HD，也不据此声称信息页已经实测更新。

`"1.0"` 是保守的发现值，不是 TCK 通过或完整 M3G 1.1 兼容声明。设备属性覆盖、运行时属性、port 查询与平台兜底的既有优先顺序保持不变。已有渲染能力布尔值和其他上限值未更改；没有新增 builtin 方法、字段或存档布局。

`maxViewportDimension` 补的是**查询键**。现有 `setViewport` 尚未按非正尺寸或大于 `4096` 的尺寸抛出规范要求的异常；本轮未修改该方法。查询表关系测试不能证明这些 setter 参数边界已经落实。

实现见 [System 属性实现](../../src/core/nj_lib_system.c)、[M3G 查询表](../../src/midp/nj_lib_m3g.c)；回归见 [VM 测试](../../tests/test_vm.c)。

## 验证

扩展已有 `test_vm`，保留原来的三个 HelloWorld 创建、运行、销毁轮次及相同清理统计，再在独立 VM 中通过公共 Java API 检查 null、空键、未知键、M3G 版本，以及四个 `Integer` 属性的类型和值。查询返回的 Hashtable 在后续字符串分配期间保持显式 GC root，并检查 root 插入成功。

同一冻结 fixture、每档同一目标文件分别链接旧库与新库：

| 路径 | normal | strict |
| --- | --- | --- |
| 旧库 `test_vm` | 三轮原测试通过；恰好三个新失败 | 同左，无 sanitizer 错误 |
| 新库 `test_vm` | 全部通过 | 全部通过 |
| 新库既有 `test_m3g` | 935 checks，0 failures | 935 checks，0 failures |

旧库的三个失败分别是空键未抛 IAE、缺少版本值、缺少 `Integer maxViewportDimension`。strict 使用 ASan、UBSan、float-cast-overflow、不可恢复错误及 leak 检查；补丁的两个运行时 TU 和新 fixture 使用 `-Wall -Wextra -Werror`。两档库各有 76 个成员，只替换 System 与 M3G 两个同名成员，其他 74 个成员及顺序逐字节保持一致。

所有构建、链接和执行均在独立私有目录中进行。没有重新跑完整 170 项测试、关闭 M3G 的构建矩阵、游戏、性能基准或设备验证。本轮没有修改主 build、原始 JAR、用户存档。

## 规范依据

- [M3G Package Discovery](https://nikita36078.github.io/J2ME_Docs/docs/jsr184/javax/microedition/m3g/package-summary.html#package_description)：通过 `microedition.m3g.version` 发现 API。
- [CLDC 1.1 System.getProperty](https://docs.oracle.com/javame/config/cldc/ref-impl/cldc1.1/jsr139/java/lang/System.html#getProperty(java.lang.String))：null 参数为 NPE，空键为 IAE。
- [Graphics3D.getProperties](https://nikita36078.github.io/J2ME_Docs/docs/jsr184/javax/microedition/m3g/Graphics3D.html#getProperties())：表始终包含 `maxViewportDimension`，其值为宽、高上限的较小值。
