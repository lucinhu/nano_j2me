# FSR1 放大改为立方核重建 + RCAS（2026-11-27）

对照版本为 `1a098a6`（0.5.51）。0.5.51 的 FSR1 由 EASU 把画面重建到每轴最多 2×，
再用 RCAS 锐化；超过 2× 时旧实现把 2× 网格线性插值到视口，文字和 2D 像素画在这一步
明显发软。本轮把放大路径统一为：立方核（Keys 曲线，A=0.10）直接从原始纹素重建到
视口尺寸，再用 RCAS 在重建后的像素上锐化；EASU 实现已删除。

## 真值方法

真值来自同一帧的原生高分渲染，而不是对低分辨率画面的插值：

| 素材 | 原生参考 | 逻辑帧 | 说明 |
| --- | --- | --- | --- |
| 田园物语 零售版第 1080 帧（2D 对话框/地图） | 1920×2560（8×） | 240×320 | `--render-scale 8` 直接渲染 |
| 毁灭战士 3 第 240 帧（M3G 3D 走廊） | 1920×2560（8×） | 240×320 | `--render-scale 8`，与 1× 同一按键序列 |

每组指标的参考图 = 原生 8× 画面按**精确覆盖面积**缩到目标尺寸，源图 = 原生画面按
同样的面积平均缩到 240×320。指标为 RGB 平均绝对误差（0–255）、SSIM（8×8 块）和
亮度梯度误差。取样脚本：`.local-tools/debug-runs/fsr-quality-round2/`、
`.local-tools/debug-runs/fsr-quality-round3-3d/`。

## 核参数

Keys 族为 `w(t) = (A+2)|t|³-(A+3)|t|²+1`（|t|≤1）、`A|t|³-5A|t|²+8A|t|-4A`
（1<|t|<2），A=-0.5 即 Catmull-Rom。在两张真值上扫参数，A≈0.10 的 MAE 与 SSIM
最好，过冲比 Catmull-Rom 小；A>0.35 开始损失 SSIM。整数倍率时所有偏心率权重为 0，
输出是精确纹素复制，像素画不会被抹平。

## 放大到 6×–8×（田园物语，原生 8× 真值）

8× 输出就是真值本身：240×320 的内部帧直接放大到原生 1920×2560。旧实现的 EASU
网格在这一步只能线性插值，新增实现则在原始纹素上重建，因此差距随倍率扩大。

| 目标尺寸 | 0.5.51 FSR1 | 新 FSR1（立方+RCAS） | 纯立方（bicubic 模式） |
| --- | --- | --- | --- |
| 1440×1920（6×） | 5.568 / 0.8301 / 9.016 | **4.375 / 0.8872 / 7.463** | 4.603 / 0.8786 / 7.466 |
| 1920×2560（8×） | 5.682 / 0.6773 / 8.493 | **4.595 / 0.7383 / 7.207** | 4.743 / 0.7418 / 7.190 |

高倍率下 SSIM 会下降是因为原生 8× 画面包含逻辑帧里根本没有的高频纹理，任何空间
放大都无法凭空恢复；误差仍比旧版低约 20%。

## M3G 3D 真值（毁灭战士 3 第 240 帧）

| 目标尺寸 | 0.5.51 FSR1 | 新 FSR1（立方+RCAS） | 纯立方（bicubic 模式） |
| --- | --- | --- | --- |
| 480×640（2×） | 3.417 / 0.9436 / 3.192 | 3.324 / 0.9451 / 2.961 | **3.133 / 0.9570 / 2.320** |
| 720×960（3×） | 3.307 / 0.9504 / 2.291 | 3.273 / 0.9514 / 2.334 | **3.176 / 0.9564 / 2.033** |
| 781×1045（3.25×） | 3.301 / 0.9497 / 2.093 | 3.247 / 0.9499 / 2.164 | **3.144 / 0.9562 / 1.811** |
| 1080×1920（4.5×） | 3.379 / 0.9427 / 1.684 | 3.265 / 0.9476 / 1.659 | **3.229 / 0.9501 / 1.458** |

3D 内容上 RCAS 比纯立方略损指标（约 0.04–0.19 MAE），因为 PBR 材质的噪声被
锐化放大；但它仍全面好于旧版，且 2D 文字收益远大于此。因此保留两个模式：
**FSR1 = 立方重建 + RCAS**（追求清晰，适合 2D 与文字），**bicubic = 纯立方**
（追求柔和与低噪声，适合纯 3D 画面）。锐度滑杆（默认 0.87）只作用于 FSR1。

## 开销与真实窗口

在 240×320 的 3× 窗口（781×1051，游戏区 720×960）用真实 SDL2 GLES2 呈现回放：
新旧窗口回读像素 437,943 / 820,831 不同（>2/255，53.4%），MAE 3.076；呈现耗时
中位数 3.126 → 3.396 ms，p95 3.885 → 4.308 ms（RTX 5080，40 帧）。多出的成本是
一次全尺寸中间渲染 + RCAS pass，换来 2D 误差 5.204 → 3.946。桌面窗口回读截图见
`docs/images/fsr-window-compare.png`。

`--upscale fsr --upscale-scale N` 的结果尺寸与旧版一致（中间尺寸语义不变），
只是滤波质量不同；`--upscale bicubic` 仍是不锐化的立方核。
