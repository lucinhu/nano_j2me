# 孤岛余生2：英文版“序章停滞”是按键假设错误（2026-10-22）

## 背景

[语料清单](2026-10-17-download-corpus.md) 的 jar-10 行长期记着：英文版
（`/home/lucinhu/Downloads/jar/孤岛余生2时间之谜.jar`）进 Play Game 后停在序章
第 1 页、约 15 秒自动翻到第 2 页就不动了，长按回车 3 秒/退格/长按下/数字 5 均
无效；中文版（jar-11）能继续进第一幕，因此当时把英文版当开放问题。

本轮按“先确认这是不是 staging（按键）问题”复查，结论是：**它不是停滞，是按键
不对**。这个标题的对话/过场翻页挂在**软键**上（画面右下角写着 `Next`），
`Return`/数字/方向键都不会翻页；用 F1/F2（左/右软键）即可推进。

## 复现与观察

环境：默认 `build/nj2me`、SDL2 端口 240×320、`--fps 30 --heap 16`、干净 RMS、
netfail 垫片（`NJ_NET_FAIL=1`，只用于跳过启动网络的 DNS/TCP 等待）。原版 JAR
运行前后 SHA-256 未变。证据目录
`.local-tools/debug-runs/corpus-round20-20261021/stranded-en/` 与
`.../stranded-cn/`。

英文版 `stranded-en/`：

1. `Return` 进 Play Game 后到序章叙事页（HUD 血条/体力条 + 文本面板），
   `p1`/`p2`/`p3`（间隔 8 秒）文本区逐像素相同，`p3` = `5cce7288…`；
   期间 `Return`、`5`、`Right`、`Down` 各按一次，文本面板仍然 0 变化 →
   **这些键不翻页**，与旧记录一致。
2. 按 `F1`（左软键）后离开叙事页，进入游戏内 **ITEMS** 画面
   （`g2` = `a2b67c46…`，31 色，`No items`）。
3. 在 ITEMS 上点一下屏幕（虚拟触摸屏 `pointer-20261022/vptr`）回到场景，
   出现对白 `The boat is ruined. I'll have to find a way to get off this
   island.` + 右下 `Next`（`q5`/`i1` = `15b8bc9c…`，Act 1 的等距岛屿、
   角色、HUD）。
4. 按 `F2`（右软键）连续推进对白：`k1` = `82853e8b…`（540 色）→ 再按一次
   文本变化（`k1`→`k2` 283552 px 差）；即 **F2 = 画面上的 `Next`**。
5. `F1` 在场景里打开 ITEMS（`g2`），`F2` 在对白里翻页——两个软键行为稳定。

中文版 `stranded-cn/`（对照）：

1. 标题 → 日期卡 `June 17, 2013 19:05`，底部提示
   `Press 0 or click to continue`（`c2` = `37d1bddd…`）；
   在本会话里 `0`、`Return`、点屏幕都没有反应。
2. 按 `F1`（左软键）后进入 `读取中` 4/5 进度画面（`f1` = `919882d5…`），
   约 10 秒加载完进入 `第一章` 卡（`l2` = `df734b48…`）→ 中英文都靠软键推进。

## 结论

- jar-10 英文版“序章停滞”撤回：序章页之后 `F1` 离开叙事页、`F2` 翻对白，
  可以进入第一幕的实际场景（等距岛屿 + 角色 + 对白 + HUD + ITEMS）。
- 这个标题（中英文同版式）把“继续/Next”放在**右软键**，把“菜单/物品”放在
  **左软键**；`Return`/数字/方向键不承担对话翻页。旧记录里的“长按回车无效”
  因此是预期行为，不是兼容性缺口。
- “Press 0 or click”提示与实体键行为不完全一致（本会话 `0` 无效），但软键可用；
  记录为标题自身的提示文案差异，未做运行时修改。

## 边界

- 未验证：第一幕内的移动/拾取/战斗、物品栏交互、存档与冷启动。
- 本轮只用键盘+虚拟触摸屏回放；Android 未测。
- 未解包该 JAR 反编译按键处理，所以“`0` 为什么无效”没有代码级结论，只有行为
  证据；不据此改动运行时。
