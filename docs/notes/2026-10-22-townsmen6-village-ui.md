# 家园6（Townsmen 6）N73 变体：村庄内行动菜单与村庄信息面板（2026-10-22）

## 目的

目标②要求补齐族群内每个 JAR 的阶段、截图与复现流程。本页记录 jar-24
（家园6 N73 240×320 变体）从开局推进到村庄 UI 的可复现步骤、可用的菜单/面板，
以及仍然卡住的“村民选择/建造”一步。

原始 JAR：`/home/lucinhu/Downloads/jar/家园6之革命完美汉化版_诺基亚 N73系列(240x320).jar`
（未修改）。默认构建 `/home/lucinhu/workspace/c/nano_j2me/build/nj2me`（HEAD `dfbc08f` 附近），
全新 RMS，SDL2 240×320、heap 16、fps 30，`netfail` 测试垫片跳过开局联网等待。

## 复现步骤与证据

1. 开局“打开声音?”提示：`Return`（fire）确认“否”，约 8 秒后进入 18 世纪法国战役地图
   （`jar24-build/06-after-fire2.png`，SHA-256 `47cfbf2100fd8bfa…`）。
2. 连续 `Return` 推进剧情对白：约 4–6 次后进入村庄等距地图，出现“早上好！大懒虫，快起床！”
   等对白（`jar24-build/09.png`，`f92fa26650d3399e…`）。
3. 教程继续推进时按 `Return` 会打开**行动菜单**：屏幕底部“行动菜单”+ 四个图标
   （旗帜、状态/恢复图标、资源桶、书本），旁边是村庄地图（`jar24-build/d28.png`，`a239fbeb22c50a56…`）。
4. 在村庄界面按数字键 `1`/`2` 打开**村庄信息面板**：左侧人口 3+3、工人 3、右侧进度条与
   `0s` 等状态；右下软键为 `切换窗口`（`jar24-build/r1.png`，`a3bc1111e7350c0e…`；
   `jar24-build/r2.png`，`568c2273b726b19c…`）。面板下方 `Return` 可关闭。
5. 村庄界面按 `F2`（右软键）打开暂停菜单：`继续游戏 / 关闭游戏 / 选项设置 / 帮助指南`
   （`jar24-build/c-f2.png`，`16987fa6a6b594e7…`）；`Return` 选“继续游戏”返回。
6. 教程随后用 HUD 图标讲解：右上数字=待业村民、房屋图标=住房不足、水滴=未挖井、
   太阳=天气（`jar24-build/e-f1.png`，`f3be61e69ad58d38…`）。
7. 教程结束后回到村庄正常游玩：蓝色箭头与手形指针指向村民/伐木屋，指示需要选中村民
   （`jar24-build2/s20.png`，`a2a2c4a1db6f67c9…`；手形指针 `jar24-build2/u1.png`，
   `f8d44173d788920e…`）；方向键滚动地图有效（`jar24-build2/u3.png`，`e14840db190a1c04…`）。
8. 运行收尾：约 20000 帧 / 443 s / 45 fps，`exit status 0`，`threads=7 gc=12`，
   释放 3327 host blocks（`jar24-build/run.log`）。

## 仍未打通：选中村民与建造

- 教程提示需要选中村民（手形指针指向村民），之后才能下令采集/建造；
  但本环境桌面指针注入不可用：该 X 显示上 `XTestFakeMotionEvent/ButtonEvent`
  返回成功却不产生指针事件（详见 [文明5 回合按钮与指针通道](2026-10-22-civ5-turn.md)），
  `xdotool click` 无法送达游戏窗口，数字键/方向键也没有推出可移动的虚拟光标。
- 因此“选中村民 → 建造/采集/战斗/存档”仍未验证；本页只证明村庄 UI、行动菜单、
  村庄信息面板、暂停菜单与地图滚动可用。
