# 家园6（Townsmen 6）N73 变体：村庄内行动菜单与村庄信息面板（2026-10-22）

## 目的

目标②要求补齐族群内每个 JAR 的阶段、截图与复现流程。本页记录 jar-24
（家园6 N73 240×320 变体）从开局推进到村庄 UI 的可复现步骤、可用的菜单/面板，
以及仍然卡住的“村民选择/建造”一步。

原始 JAR：`/home/lucinhu/Downloads/jar/家园6之革命完美汉化版_诺基亚 N73系列(240x320).jar`
（未修改）。默认构建 `/home/lucinhu/workspace/c/nano_j2me/build/nj2me`（HEAD `dfbc08f` 附近），
全新 RMS，SDL2 240×320、heap 16、fps 30，`netfail` 测试垫片跳过开局联网等待。

## 复现步骤与证据

1. 开局“打开声音?”提示：`Return`（fire）确认“否”，约 8 秒后进入 18 世纪法国战役地图
   （`jar24-build/06-after-fire2.png`，SHA-256 `47cfbf2100fd8bfa…`）。
2. 连续 `Return` 推进剧情对白：约 4–6 次后进入村庄等距地图，出现“早上好！大懒虫，快起床！”
   等对白（`jar24-build/09.png`，`f92fa26650d3399e…`）。
3. 教程继续推进时按 `Return` 会打开**行动菜单**：屏幕底部“行动菜单”+ 四个图标
   （旗帜、状态/恢复图标、资源桶、书本），旁边是村庄地图（`jar24-build/d28.png`，`a239fbeb22c50a56…`）。
4. 在村庄界面按数字键 `1`/`2` 打开**村庄信息面板**：左侧人口 3+3、工人 3、右侧进度条与
   `0s` 等状态；右下软键为 `切换窗口`（`jar24-build/r1.png`，`a3bc1111e7350c0e…`；
   `jar24-build/r2.png`，`568c2273b726b19c…`）。面板下方 `Return` 可关闭。
5. 村庄界面按 `F2`（右软键）打开暂停菜单：`继续游戏 / 关闭游戏 / 选项设置 / 帮助指南`
   （`jar24-build/c-f2.png`，`16987fa6a6b594e7…`）；`Return` 选“继续游戏”返回。
6. 教程随后用 HUD 图标讲解：右上数字=待业村民、房屋图标=住房不足、水滴=未挖井、
   太阳=天气（`jar24-build/e-f1.png`，`f3be61e69ad58d38…`）。
7. 教程结束后回到村庄正常游玩：蓝色箭头与手形指针指向村民/伐木屋，指示需要选中村民
   （`jar24-build2/s20.png`，`a2a2c4a1db6f67c9…`；手形指针 `jar24-build2/u1.png`，
   `f8d44173d788920e…`）；方向键滚动地图有效（`jar24-build2/u3.png`，`e14840db190a1c04…`）。
8. 运行收尾：约 20000 帧 / 443 s / 45 fps，`exit status 0`，`threads=7 gc=12`，
   释放 3327 host blocks（`jar24-build/run.log`）。

## 仍未打通：选中村民与建造

- 教程提示需要选中村民（手形指针指向村民），之后才能下令采集/建造；
  但本环境桌面指针注入不可用：该 X 显示上 `XTestFakeMotionEvent/ButtonEvent`
  返回成功却不产生指针事件（详见 [文明5 回合按钮与指针通道](2026-10-22-civ5-turn.md)），
  `xdotool click` 无法送达游戏窗口，数字键/方向键也没有推出可移动的虚拟光标。
- 不过当天晚些时候打通了桌面指针通道（uinput 虚拟触摸屏 + `F12/Tab` 隐藏模拟器键盘覆盖层，
  见 [桌面指针注入](2026-10-22-desktop-pointer.md)）；在村庄画面上按村民所在位置注入多次点击，
  已能送达 MIDP（指针按下/抬起），但按当前坐标点到的位置没有出现可辨认的选中框或行动菜单，
  村民/地块命中区域仍需下一轮继续找。

## 2026-10-22 第三轮：行动菜单（建造入口）已能打开，但菜单项不响应

用虚拟触摸屏（长按 400–450 ms；`Tab` 隐藏模拟器键盘覆盖层，颜色数 1069→677）继续试村庄交互：

- **行动菜单能打开**：长按底部“行动菜单”条（窗口坐标约 480,1215）后，整屏出现三栏行动菜单
  （`jar24-touch2/e1-actionbar.png`，SHA-256 `fe97e537ea1b5dc0…`）：
  - 左栏“居民”：增加居民、显示居民信息等；
  - 中栏“建造”：居民住房、建造水井、建造木匠房、建筑列表；
  - 右栏“其他”：游戏菜单、村庄信息等。
  这证明桌面指针已经能驱动游戏的触摸菜单（之前只能靠键盘到村庄）。
- **但菜单项不响应**：按图标中心坐标（中栏图标约在 413/510 × 467/593 窗口像素）做短按(120 ms)、
  长按(450 ms)，以及 `Return`/`Down`/`5`，截图全部 **0 像素变化**
  （`h2-house-hold.png` 与 `e1-actionbar.png` 哈希相同，`fe97e537…`）。
  菜单看起来是“画出来但不接受输入”的模态层，原因未知；下一轮可试 `Up/Left/Right/F1/F2`、
  点“其他/居民”栏、或先关闭菜单再沿教程蓝箭头重新选村民。
- 村民/教程：短按曾让教程手形消失（`c2-short.png`，`a0facd108f90304f…`），但村民会走动，
  按固定坐标点击不可靠；固定坐标长按无选中框。
- 顺带发现音频兼容缺口：`run.log` 反复出现
  `javax/microedition/media/MediaException … not a PCM WAV: cannot parse the media`
  （家园6 的 WAV 解析失败，游戏自行捕获、不影响 UI/输入），可留作后续音频兼容项。

## 2026-10-22 第四轮：教程弹窗会挡住输入；键盘可开面板

为了解释“行动菜单画出来却不吃输入”，重跑一遍并把中间态逐帧看了：

- 进入村庄后，教程会先压一个半透明**教程文本面板**（`jar24-touch3/a1.png`，
  SHA-256 `fcefffd775b3023e…`），提示要建住所之类；此时 `Return`/`F1`/`F2`/`5`/`*`
  都不是“翻页”，而是直接改变界面（见下）。上一轮“长按打开的菜单项不响应”，很可能是因为
  **这个教程模态页还没结束**，菜单只是被画出来、输入被教程流程吃掉。
- 教程状态下按键效果（每次间隔 2.5 s，截图与前一态比较）：
  - `5` → 打开左下的**居民面板**（4 个村民头像、其中一位被黄框选中，
    `jar24-touch3/t-5.png`，SHA-256 `48d732588589df52…`）；
  - `*` → 显示“教程”提示浮层 + 居民面板/村庄（`t-asterisk.png`，`0ff9e62ece87ff7b…`）；
  - `F1` 94,535 px、`F2` 27,584 px 变化（面板切换），`Return` 只翻教程文本、`#`/`Escape` 无变化。
- 教程页在 `5` 之后消失、村庄恢复可玩；此后 `F1` 无变化、`2` 有 7,821 px 变化
  （`u2-2.png`，`dc9926bf1056cf7b…`，底部行动菜单图标高亮变化但未确认进入了建造子菜单）。
- 结论/下一步：先在**教程结束后**再用长按行动菜单→建造项，重试建造流程；若仍不响应，
  则换“键盘 F1 + 数字/方向键”的路径（当前证据显示键盘能驱动面板）。
- 本轮仍未验证：建造、采集、战斗、存档。指针事件在本轮未注入（纯键盘），
  上一轮的指针证据仍以文明5 的 `NJPTR` 日志为准。
