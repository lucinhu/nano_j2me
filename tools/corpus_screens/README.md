The probes measure every title at 240x320 unless a file here says
otherwise.  Each file is named after the JAR without its extension and
contains one of: 240x320, 320x240, 176x208, 128x160.

A JAR whose name carries a _<w>x<h> suffix (for example
`Carcassonne_1.0.8_320x240.jar`) is already measured at that size; this
directory exists for titles whose file name does not say it but whose
assets are built for a landscape screen.
